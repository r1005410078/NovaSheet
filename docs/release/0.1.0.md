# NovaSheet 0.1.0 Release Notes

NovaSheet 0.1.0 is the first planned public package milestone for the monorepo. It packages the current Canvas-first spreadsheet engine work into a reviewable release boundary for contributors, adopters, and open-source program reviewers.

This release has not been published to npm yet. The checklist in [docs/npm-publishing.md](../npm-publishing.md) must be completed before creating a public tag or package release. Package versioning and publication are managed with Changesets.

## Scope

- `@novasheet/core`: portable spreadsheet engine primitives with no DOM or Canvas dependency.
- `@novasheet/web`: browser host/runtime primitives.
- `@novasheet/canvas2d`: Canvas2D renderer and painter layer.
- `@novasheet/sheet`: browser-facing `Grid` facade and default runtime integration.
- `apps/storybook`: public interactive demo for manual validation and API exploration.

## Highlights

- Canvas-first rendering architecture for large spreadsheet-style datasets.
- Native scroll host with virtualized row and column mapping.
- Frozen top, left, and right regions.
- Dynamic row height and multiline autofit support.
- Spreadsheet interactions including selection, keyboard navigation, editing, clipboard, undo/redo, fill handle, sorting, filtering, row and column operations, column reorder, merge cells, and basic range formatting.
- Storybook examples for the main interaction and rendering variants.
- MIT license, contribution guide, security policy, issue templates, pull request template, and CI gates.

## Validation

Run these commands from the repository root before tagging or publishing:

```bash
bun install
bun run lint
bun run typecheck
bun test
bun run build
STORYBOOK_BASE_PATH=/NovaSheet/ bun run build-storybook
```

Current baseline at the time this release note was created:

- `842` tests with `bun:test`
- CI gates: lint, typecheck, test, build
- Demo target: GitHub Pages Storybook
- Release manager: Changesets

## Known Limitations

- NovaSheet is pre-1.0; public APIs may still change.
- npm packages are not yet published.
- Advanced borders, number/date/percent/currency formatting, conditional formatting, formulas, import/export, multi-sheet workflows, and framework adapters are roadmap items.
- The current workspace package exports are optimized for local development. Before npm publication, confirm that published package manifests only reference files included in each package tarball.

## Release Checklist

- Confirm package versions and changelog entry.
- Confirm the initial Changesets entry bumps publishable packages to `0.1.0`.
- Confirm each publishable package builds `dist` artifacts.
- Run `npm publish --dry-run` or equivalent package tarball inspection for every publishable package.
- Publish packages in dependency order: `@novasheet/core`, `@novasheet/web`, `@novasheet/canvas2d`, `@novasheet/sheet`.
- Create a `v0.1.0` git tag after package tarballs are verified.
- Create a GitHub release that links to the live Storybook demo and this release note.
