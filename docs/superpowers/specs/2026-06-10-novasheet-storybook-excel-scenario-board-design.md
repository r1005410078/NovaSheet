## 1. 背景与目标

21 条 NovaExcel L3 行为场景已有 manifest、mbd 校验与 `lint:scenario-coverage` 门禁，但 **Storybook 缺少一张可浏览的「用例完成度矩阵」**。本设计在 Storybook 新增 **方案 1**：用 **NovaExcel 自身** 渲染场景清单，并用 **`setFillColor`** 以填充色标记每条场景是否已被行为测试覆盖。

### 成功标准

| 指标 | 目标 |
| --- | --- |
| Storybook story | `Table/React` 下新增 **Excel Scenario Board**（名称可微调） |
| 行数 | 表头 1 行 + **21** 条场景（与 manifest 同步） |
| 填色 | 有对应 `it('excel.L3x…')` → 绿；缺失 → 红 |
| 数据源 | 构建/dev 前生成，与 `check-scenario-coverage` **同源逻辑** |
| 测试 | 1 条 story smoke（挂载 + 行数 + 绿格数量） |
| 回归 | 不新增 L3 行为测；不重复 21 条引擎断言 |

### 非目标

- 在 Storybook 内实时执行 `bun test`
- 点击行跳转 MD / 打开独立 demo story
- 双向编辑 manifest `status`
- 21 个独立 story 文件
- 将看板逻辑并入 `@novasheet/mbd` CLI

## 2. 方案选定

用户确认 **方案 1：NovaExcel 场景矩阵**。

| 维度 | 决策 |
| --- | --- |
| 展示载体 | `NovaExcel` + `InMemoryDataSource` |
| 完成定义（MVP） | **结构覆盖**：manifest id 在 `packages/react/tests/excel/**/*.test.ts(x)` 标题中出现即「完成」 |
| 填色 API | 挂载后对状态列（或整行）调用 `grid.setFillColor` |
| 工具栏 | `showToolbar: false`（只读看板，减少干扰） |
| excelWorkspace | `false`（固定 21 行，非稀疏无限表） |

### 2.1 完成态语义（MVP）

与 `lint:scenario-coverage` 一致，复用 `computeScenarioCoverage` / `scanScenarioIdsFromSource`：

| `coverage` | 填色 | 状态列文案 |
| --- | --- | --- |
| `covered` | `#34a353`（与 toolbar 绿块一致） | `完成` |
| `missing` | `#ea4335`（与 toolbar 红块一致） | `缺失` |

manifest frontmatter 的 `status: draft | implemented` **仅作信息列展示**（可选列 F），**不参与** MVP 填色。二期可将 `implemented` 与填色规则叠加。

### 2.2 表格列布局

| 列 id | 表头 | 内容 |
| --- | --- | --- |
| `layer` | Layer | L3a / L3b / L3c |
| `id` | Scenario ID | `excel.L3a.default-mount` |
| `summary` | Summary | manifest `summary` |
| `coverage` | 测试覆盖 | `完成` / `缺失`（**本列填色**） |
| `userStory` | User Story | manifest `userStory`（允许多行 `textWrap: 'wrap'`） |

行序：manifest 顺序（已与 layer 分组一致）。

表头行（row 0）：文本 + 可选浅灰底 `#f3f3f3`，不标红绿。

## 3. 架构

```text
scenarios.manifest.json
        +
packages/react/tests/excel/**/*.test.ts(x)   ← scanScenarioIdsFromSource
        ↓
sync-excel-scenario-board.ts（storybook 脚本）
        ↓
apps/storybook/src/generated/excel-scenario-board.ts
        ↓
ExcelScenarioBoard.stories.ts
  → InMemoryDataSource(rows)
  → NovaExcel(showToolbar: false)
  → on mount: grid.setFillColor(状态列, color)
```

### 3.1 生成脚本

**路径**：`apps/storybook/scripts/sync-excel-scenario-board.ts`

**职责**：

1. `readManifest`（`@novasheet/mbd`）读取 `packages/react/tests/excel/scenarios.manifest.json`
2. 扫描 `packages/react/tests/excel` 下 `*.test.ts(x)`，收集 scenario id
3. 调用 `computeScenarioCoverage`（从 `@novasheet/react` 的 `check-scenario-coverage` 模块 **导出复用**，或 storybook 脚本相对 import `packages/react/scripts/check-scenario-coverage.ts`）
4. 写出 `apps/storybook/src/generated/excel-scenario-board.ts`：

```ts
/** @generated by sync-excel-scenario-board — do not edit */
export interface ExcelScenarioBoardRow {
  readonly layer: string
  readonly id: string
  readonly summary: string
  readonly userStory: string
  readonly manifestStatus: 'draft' | 'implemented'
  readonly coverage: 'covered' | 'missing'
  readonly fillColor: '#34a353' | '#ea4335'
}

export const EXCEL_SCENARIO_BOARD_ROWS: readonly ExcelScenarioBoardRow[] = [ ... ]
export const EXCEL_SCENARIO_BOARD_GENERATED_AT = '...'
export const EXCEL_SCENARIO_BOARD_STATS = { covered: 21, total: 21 }
```

**触发时机**（`apps/storybook/package.json`）：

- `prestorybook` / `prebuild-storybook`：`bun run sync:excel-scenario-board`
- 根 `package.json` 可选：`sync:excel-scenario-board` 转发，便于 CI `build-storybook` 前手动跑

**与 lint 关系**：生成脚本 **不替代** `lint:scenario-coverage`；若 manifest 与测试漂移，看板与 lint 同时反映（看板红格、lint fail）。

### 3.2 Story 实现

**路径**：`apps/storybook/src/stories/ExcelScenarioBoard.stories.ts`

**模式**：与 `NovaExcel.stories.ts` 相同 — `@storybook/html` + `createRoot` + `React.createElement`。

**挂载后填色**（小型内联 React 组件或 `useLayoutEffect`）：

1. `ref` 取 `NovaExcelRef`
2. `grid.setFillColor({ startRow, startCol, endRow, endCol }, fillColor)` 对每行 `coverage` 列
3. 可选：对 `userStory` 列 `grid.setTextWrap(range, 'wrap')`

**Schema**：story 内局部 `scenarioBoardSchema()`，五列 field id 见 §2.2。

**Docs**：`docsMeta` 说明看板用途、绿/红含义、`bun run sync:excel-scenario-board` 与改场景 MD 后的刷新步骤。

### 3.3 测试

**路径**：`apps/storybook/src/stories/ExcelScenarioBoard.stories.test.ts`

| 断言 | 说明 |
| --- | --- |
| story `render()` 不抛错 | 组合根 smoke |
| `EXCEL_SCENARIO_BOARD_STATS.total === 21` | 与 manifest 对齐 |
| 挂载后 DOM 含 `data-novasheet-react-excel` | NovaExcel 壳层 |
| 绿格数量 === `stats.covered` | 可通过 data attribute 或 grid API（若 test 能取 ref） |

不断言单条场景文案（避免与生成文件双维护）。

### 3.4 Git / 生成物

- `apps/storybook/src/generated/` 加入版本库（与 `generated-data-source` 模式一致），CI `build-storybook` 前 `prebuild` 再生成一次保证新鲜
- `.gitignore` 不排除该文件

## 4. 依赖与边界

| 包 | 变更 |
| --- | --- |
| `apps/storybook` | 脚本 + story + test + generated |

## 5. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 生成脚本与 lint 逻辑分叉 | 共用 `computeScenarioCoverage` + `scanScenarioIdsFromSource` |
| `userStory` 列过高 | `textWrap: 'wrap'` + 固定 viewport 高度 + 纵向滚动 |
| Storybook typecheck 既有 `@/` 失败 | 本 story 不引入 `@/`；全量 typecheck 失败记为既有债，不阻塞本 feature |
| manifest 变更忘记 sync | `prestorybook` hook + 文档说明 |
