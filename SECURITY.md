# Security Policy

## Supported Versions

NovaSheet is pre-1.0. Security fixes are handled on the `main` branch until versioned releases begin.

## Reporting a Vulnerability

Please do not open public issues for suspected security vulnerabilities.

Report privately through GitHub Security Advisories when available. If that is not available, open a minimal public issue asking for a private contact channel without disclosing exploit details.

Please include:

- Affected package or workflow
- Steps to reproduce
- Impact and severity estimate
- Any known mitigations

Maintainers will acknowledge reports as soon as possible and coordinate a fix before public disclosure.
